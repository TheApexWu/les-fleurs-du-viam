# Viam machine config (armfarm12)

`armfarm12-config.json` is the machine part's config as returned by the Viam app API
(`app_client.get_robot_parts`), exported 16 Oct 2026 ~3:30 pm. The arm's LAN IP and the camera serial
are redacted. It is a snapshot for reference and review; the live config is in the Viam app.

Re-export (needs the machine API key in `.env`): see `export_config.py` in this folder.
